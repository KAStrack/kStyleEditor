Let your users style it, without letting them break it.

kStyleEditor takes over a <textarea> and puts a visual style editor in its place: colours, fonts, spacing, borders, shadows and fifty-odd more. Every change writes plain CSS declarations back into the textarea, so your form posts exactly as it always did, and a one-line SDK call on the server makes that CSS safe to render.

No dependencies No build step ~17 KB of JS, gzipped Live preview PHP · Python · Node · C# · Go · Ruby SDKs MIT

Open the playground Read the docs

Try it

A form builder usually stores one piece of CSS per element. Pick an element, change anything, and it restyles as you go. Each one has its own <textarea> and its own editor; the panel underneath shows what a server would render from them.

On the server

    

      Whatever reaches your server came from a browser, so treat it as untrusted. Each SDK
      parses the declarations, keeps only allowed properties with safe values, and can wrap
      the result in your selector, ready to drop into a <style> block.
    


// PHP
echo Kastrack\StyleEditor\Css::sanitize($row['css'], ['selector' => '#field-12']);

# Python
kstyle_editor.sanitize(row.css, selector="#field-12")

// Node
require('@kastrack/style-editor').sanitize(row.css, { selector: '#field-12' });
